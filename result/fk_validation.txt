[1:N 관계와 도메인 의미]
1) genre 1:N movie
   하나의 장르에는 여러 영화가 속할 수 있다. movie.genre_id가 genre.genre_id를 참조한다.
2) member 1:N review
   한 회원은 여러 리뷰를 작성할 수 있다. review.member_id가 member.member_id를 참조한다.
3) movie 1:N review
   한 영화에는 여러 회원의 리뷰가 작성될 수 있다. review.movie_id가 movie.movie_id를 참조한다.

[각 FK 무결성 실패 테스트]
1) movie.genre_id -> genre.genre_id
   결과: FOREIGN KEY constraint failed
2) review.member_id -> member.member_id
   결과: FOREIGN KEY constraint failed
3) review.movie_id -> movie.movie_id
   결과: FOREIGN KEY constraint failed

[문제 해결 과정]
VS Code SQLite Extension에서 SQL 문서/연결에 따라 PRAGMA foreign_keys가 0으로 보이는 경우가 있었다.
SQLite FK 강제(enforcement)는 DB 파일의 영구 설정이 아니라 연결 단위 설정이므로, FK 테스트와 동일한 연결에서 PRAGMA foreign_keys = ON;을 실행하고 PRAGMA foreign_keys;가 1인지 확인했다.
또한 FK가 스키마에 정의되어 있는지(PRAGMA foreign_key_list)와 현재 연결에서 실제로 강제되는지(PRAGMA foreign_keys)를 구분해 검증했다.
